Sidephone apps

Brad White's App Pack for the Sidephone SP-01. Scan once; the apps then install and update from App Library like the official packs.

Add the pack

  1. On the Sidephone, open App Library and tap the QR code button. If there is no button, go to Settings, Repositories, tap +, then Scan QR code.
  2. Scan the code above. Adding the pack installs nothing on its own.
  3. Find the app you want in App Library and tap Install. Updates arrive the same way.

Any F-Droid client works too: Settings, Repositories, add the address below, then paste the fingerprint.

What is in it

  • Slickrock Station

    Retro game launcher for RetroArch, built for phones with real keys. Library by system with box art, and a controls editor drawn on the phone's own keys.

  • RetroArch for Slickrock

    The RetroArch build Slickrock Station launches. Installs beside the stock RetroArch and keeps its own settings. GPL; the patches are published here.

  • Tyle

    Per-tile settings for the keypad tiles: keyboard, Bluetooth, brightness and an app to open when a tile snaps on. Turn on "Tyle keys" under Accessibility after installing.

  • Levyra SP

    The Levyra music player with lighter first-run defaults for the Sidephone's screen and processor. Pick a song or artist and start a radio. Source on GitHub.

Published from github.com/Bradleyw801/sidephone-apps. Slickrock Station and Tyle are Brad White's own apps. RetroArch and Levyra are free software under the GNU GPL; this pack only carries builds of them, with the changes published alongside.
